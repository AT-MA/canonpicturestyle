# 佳能相片风格合集 Canon Picture Styles

佳能 102 种相片风格 + 富士胶片效果风格 + 佳能萤石镜头色彩，共 110 个 `.pf2` 相片风格文件。

无需复杂后期，导入相机直接出片，或在 DPP 里一键套用到 RAW 照片上。

> 注意：只能用于佳能单反或无反相机。

## 目录结构

| 文件夹 | 数量 | 说明 |
| --- | --- | --- |
| [佳能102种相片风格](佳能102种相片风格) | 102 | 佳能官方及日本摄影师（小山壮二、Kevin、Eyer 等）调校的风格：人像、风景、日系、Lomo、仿红外、富士正片等 |
| [富士胶片效果风格](富士胶片效果风格) | 5 | 富士 RDP III、RVP-100F 等胶片模拟 |
| [佳能的萤石镜头色彩](佳能的萤石镜头色彩) | 3 | 佳能 L 头萤石色彩：标准 / 人像 / 风景 |

## 使用方法

完整图文步骤见 [照片风格文件导入相机步骤.txt](照片风格文件导入相机步骤.txt)。

**导入相机**（需要安装 EOS Utility）

1. 用数据线连接相机和电脑，打开 EOS Utility
2. 进入「相机设定/远程拍摄」→「照片风格」→「设定」
3. 选择「用户定义 1 / 2 / 3」，点「打开」载入 `.pf2` 文件，再点「应用」

**后期套用**（照片需为 RAW 格式）

用 DPP 打开 RAW 照片 →「查看」→「工具调色板」→ 浏览并选择 `.pf2` 文件即可。

**推荐搭配**：用户定义只有 3 个时，可导入富士底片风格作为自定义风景，萤石色彩的「标准」和「人像」作为自定义标准和人像。

## English

Canon 102 Picture Styles + Fujifilm film simulation styles + Canon fluorite (L-lens) color styles — 110 `.pf2` files in total.

Load them into the camera as User Defined styles via **EOS Utility**, or apply them to RAW files in **Digital Photo Professional (DPP)** via View → Tool Palette.

> Note: Compatible only with Canon DSLR or mirrorless cameras.
